# Contributing

- Review `AGENTS.md` and `docs/15-AGENT-WORKFLOW.md`.
- Use small PRs, typed contracts, SQL migration discipline and test-first dispatch changes.
- PR description: scope, architecture impact, screenshots for UI, migration safety, tenant access risks, tests actually run, rollback.
- All new provider dependencies require privacy, cost, Philippine network/coverage and vendor portability review.
- No vendor secrets, personal documents or live journey coordinates in Git.
