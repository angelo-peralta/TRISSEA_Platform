# Journey Maps

## Passenger on-demand
Launch → location → choose destination → verify quote → request → searching → offered driver accepts → en-route → arrived → pickup verification → trip → receipt → rating.

### Critical negative branches
No GPS → manual location; no mobile data → draft only + retry; no driver → offer alternative; driver cancels → policy-limited rematch; user cancels → disclose any lawful applicable fee; trip discrepancy → safety/support.

## Passenger terminal
Choose terminal/route → approved pickup/boarding details → quote → confirm → queue matching → driver assigned → meet at loading point → trip → receipt. No queue: explicit alternative quotation and new consent.

## Driver on-demand
Login → approval gate → start shift → acquire permissions → online → offer → accept/decline → pickup navigation → verify boarding → active trip → finish → availability restored per policy.

## Driver terminal
Start shift → select tenant/terminal → geofence check → queue join → waiting position → pending offer → accept → queue consumed → fulfill trip → explicit rejoin (unless approved auto-rejoin rule).

## Dispatcher
Open tenant dashboard → filter terminal/service → inspect queue → identify stale/offline driver → manual pause/override with reason → audit event/notification → report.

## Passenger service selection — official four options
Home → Regular/Shared/Special/Reservation. Each card shows name, clear one-line description and availability. Do not confuse service option with dispatch mode.
- Regular → pickup → destination → private quote → match → ride.
- Shared → party size → compatible route → disclosed wait/detour → lower-fare quote → pooled pickup/individual receipt.
- Special → whole unit → ordered optional stops → optional return leg → full itinerary quote → exclusive driver.
- Reservation (passenger) → authorized TODA terminal → pickup window + destination/party size → hold/confirm → in-person check-in → fare/route consent → eligible TODA FIFO driver offer → linked ride or explained unfulfilled status.
